## 1. 목적과 범위

부모 문서가 정의한 **르네상스 미술관**이라는 분위기는 유지하되, 레퍼런스에서 빌려온 **모던 에디토리얼**의 레이아웃 어휘 — 가변 비율 bento(masonry), 큰 세리프 디스플레이 타이포, 작은 캡션 라벨, 카테고리 필터 칩, 미니멀 톱바 — 를 도입한다.

**적용 화면**: 갤러리 메인, 라이트박스, 로그인 / 초대 가입.

**적용 외**: 편집 캔버스, 휴지통, 관리자, 설정. 이들은 부모 spec §9의 기존 르네상스 폼을 유지한다 (히어로 없음·평이한 폼 카드).

이 문서에서 새로 만들지 않는다. 부모 §9.1 값을 그대로 인용한다.

|---|---|---|
| `--color-bg` | `#F5EFE4` (베이지) | `#1F1A14` (어두운 벽) |
| `--color-bg-elevated` | `#FBF6EC` (한 단계 밝은 베이지) | `#2A2218` |
| `--color-ink` | `#1B2B3A` (잉크 다크네이비) | `#F5EFE4` |
| `--color-ink-muted` | `#6E5B3F` (베이지에 어울리는 갈색) | `#C9A96A` |
| `--color-gold` | `#B8924B` | `#B8924B` |
| `--color-gold-soft` | `#D7B879` | `#8A6E3A` |
| `--color-wine` | `#7A2E2E` | `#7A2E2E` |
| `--color-border` | `#E7DDC9` | `#3A2F22` |

폰트 (부모 §9.1):
- `--font-serif`: `"Cormorant Garamond", "Noto Serif KR", ui-serif, Georgia, serif` — h1~h4, 캡션, 이탤릭 부제, 라이트박스 메타값.
- `--font-sans`: `Inter, Pretendard, ui-sans-serif, system-ui, sans-serif` — 본문, 네비, 라벨, 칩, 입력 필드.

## 3. 레이아웃 어휘

### 3.1 그리드 — 가변 비율 masonry

- 갤러리는 **CSS columns** 기반 masonry. 각 컬럼이 독립적으로 흐르며 행 정렬을 강제하지 않는다.
- 타일은 **원본 사진의 비율을 그대로** 유지한다. 서버/DB가 타일 사이즈를 결정하지 않는다.
- 영상 타일은 클라이언트에서 추출한 첫 프레임 썸네일(부모 §3.1)의 비율을 그대로 쓴다.
- 컬럼 수:
  - 모바일 (~ 639px): **2 컬럼**
  - 태블릿 (640 ~ 1023px): **3 컬럼**
  - 데스크톱 (1024px ~): **4 컬럼**
  - 와이드 (1536px ~): **선택적으로 5 컬럼** (지금은 4 유지)
- 컬럼 사이 간격(`column-gap`): 모바일 6px / 데스크톱 10px.
- 타일 사이 세로 간격(`margin-bottom`): 동일 값.
- 정렬은 시간 역순(최신이 위). 무한 스크롤 / 페이지네이션 규칙은 부모 spec의 기존 결정을 따른다.

### 3.2 캡션 규칙

캡션은 사용자가 `media.title`을 보는 위치. 그리드에서의 시각적 노이즈를 줄이기 위해 다음 규칙을 따른다.

| 컨텍스트 | 캡션 표시 |
|---|---|
| 데스크톱 그리드, 작은 타일 (짧은 변 < ~300px) | 표시 안 함 |
| 데스크톱 그리드, 큰 타일 (짧은 변 ≥ ~300px) | **호버 시** 사진 좌하단에 이탤릭 세리프로 떠오름 (그라데이션 음영) |
| 모바일 그리드 | 표시 안 함 (탭하면 라이트박스에서 본다) |
| 라이트박스 | **항상** 오른쪽 메타 패널에 표시 (§5.2) |

호버 캡션 마크업 예:
```html
<div class="tile">
  <img src="..." />
  <span class="tile-cap">제주, 둘째 날</span>
</div>
```
`.tile-cap`은 기본 `opacity: 0`, 호버 시 `opacity: 1` 트랜지션. 모바일에서는 미디어 쿼리로 영구 숨김. 큰/작은 타일 판별은 `IntersectionObserver`나 layout 측정 없이, **이미지의 원본 `width/height` 메타로 짧은 변이 300px 이상이면 `data-large`** 표식을 서버 렌더 시점에 붙이는 방식으로 처리한다 (런타임 측정 불필요).

## 4. 공통 컴포넌트

### 4.1 톱바 (`<header>`)

세 화면 모두 동일한 톱바.

```
+--------------------------------------------------+
| Gallery.        사진  영상  편집      [업로드]    |
+--------------------------------------------------+
```

- 높이: 56px (데스크톱) / 48px (모바일).
- 좌측: 워드마크 `Gallery.` — `var(--font-serif)`, italic, 17~18px, `color: var(--color-ink)`.
- 우측: 작은 영문 카피의 메뉴 항목들. `var(--font-sans)`, 11px, `letter-spacing: 0.12em`, `text-transform: uppercase`, `color: var(--color-ink-muted)`.
- CTA 알약: `var(--color-wine)` 배경 + `var(--color-bg)` 글자, `border-radius: 999px`, 라이트박스에선 "편집", 갤러리에선 "업로드", 로그인에선 표시 안 함.
- 아래 1px 보더: `var(--color-border)`.
- 모바일에선 메뉴 텍스트는 숨기고 알약 CTA만 남긴다 (햄버거 미사용 — 우측 알약을 탭하면 액션 시트).

### 4.2 칩 행 (필터)

- 갤러리에서만 사용 (라이트박스/로그인엔 없음).
- 항목: 부모 spec의 분류 필터값 (전체 / 사진 / 영상) **+** 사용자가 정의한 카테고리 — 카테고리 기능은 부모 spec §16 (스코프 밖)에 있으므로 MVP에선 **분류 필터 3종만** 표시.
- 모양: 1px 보더 알약, `padding: 5px 10px`, 11px, `var(--font-sans)`, `letter-spacing: 0.12em`, `text-transform: uppercase`.
- 활성: `var(--color-ink)` 배경 + `var(--color-bg)` 글자.
- 비활성: 투명 배경 + `var(--color-border)` 보더 + `var(--color-ink-muted)` 글자.
- 모바일: 가로 스크롤 (overflow-x: auto, scrollbar 숨김).

### 4.3 히어로 — Quiet 패턴

- 갤러리 / 로그인 양쪽에서 사용 (라이트박스는 히어로 없음).
- 페이지 타이틀(h1): `var(--font-serif)`, weight 500, `letter-spacing: -0.01em`. 사이즈:
  - 모바일 30px / 태블릿 38px / 데스크톱 44px.
- 부제(.sub): `var(--font-serif)` italic, 12~14px, `color: var(--color-ink-muted)`. 한 줄, 짧게.
- 별도 배경 띠 / 카드 / 박스 없음. 톱바 바로 아래 페이지 패딩 안에 위치.
- 갤러리 페이지 타이틀: "가족 갤러리." · 부제: "— 우리가 모은 순간들 —" (운영자가 환경변수로 바꿀 수 있게).
- 로그인 페이지: §6 참조.

## 5. 라이트박스

### 5.1 레이아웃

- 데스크톱: 좌측 = 사진 스테이지, 우측 = 메타 패널 (폭 280~320px).
- 모바일: 사진 위 / 메타 아래 스택.
- 배경: 다크 모드 전환과 무관하게 **항상 다크 우드** `#1F1A14` (= dark `--color-bg`). 사진을 그림자 위로 띄우기 위함.
- 사진은 원본 비율 유지. 짧은 변이 stage 영역에 fit. 그림자 `0 20px 50px rgba(0,0,0,.5)`.

### 5.2 메타 패널

위에서 아래로:

1. **라벨 행** — `"No. 042 · 2024.07.18"` 형식. `var(--font-sans)`, 9px, `letter-spacing: 0.25em`, uppercase, `color: var(--color-gold)`. `No.`는 시간순 일련번호 (UI 표시용; DB 컬럼 추가 안 함, 정렬 인덱스로 계산).
2. **제목(h3)** — `media.title` 그대로. `var(--font-serif)`, weight 500, 30px, line-height 1.05.
3. **이탤릭 캡션** — `media.title`이 짧을 때 별도 캡션 컬럼이 있으면 표시. 부모 spec엔 캡션 컬럼이 없으므로 **MVP에선 표시 안 함**. (스코프 추가 시 `media.caption` 컬럼 도입 결정 필요 — 부모 §16에 후보로 적어둘 것.)
4. **메타 dl** — 찍은 사람(`owner.display_name`) / 분류 (사진·영상) / 업로드 일시. `dt`는 sans uppercase 라벨, `dd`는 serif italic.
5. **액션 알약 행** — 권한별로 다름:
   - 멤버: `편집`, `다운로드`
   - 관리자: `편집`, `다운로드`, `휴지통`
   - primary는 와인 채움(`편집`), 나머지는 outline + gold 글자.

### 5.3 인터랙션

- 좌우 스와이프(모바일) / `←` `→` 키(데스크톱)로 이전·다음 미디어 이동.
- `Esc` / 배경 클릭으로 닫기.
- 영상의 경우 사진 자리에 `<video>` 컨트롤 표시 (부모 §5의 기존 결정 유지).

## 6. 로그인 / 초대 가입

### 6.1 레이아웃

- 데스크톱: 좌측 = 사진 캔버스(`grid-template-columns: 1fr 1fr`), 우측 = 폼.
- 모바일: 사진 위 / 폼 아래 스택. 사진은 비율 16:9 정도로 크롭.

### 6.2 사진 캔버스

- 풀-블리드. `url(...)` 배경, `object-fit: cover`.
- 어떤 사진을 보여줄지: **랜덤 하나** — `media`에서 `deleted_at IS NULL`이고 사진(`kind='photo'`)인 것 중 무작위 1장. 매 페이지 로드마다 갱신. (DB 부담을 줄이려면 일별 캐시: `ORDER BY id LIMIT 1 OFFSET (hash(today) % count)` 같은 방식.)
- 사용자가 로그인된 적이 없는 첫 방문에는 보여줄 사진이 없을 수도 있음 → 그땐 fallback 이미지(public 디렉토리에 한 장 두기, 르네상스 분위기 정물화 풍).
- 좌하단에 이탤릭 캡션: 부모가 환경변수로 정한 한 문장 (기본 "— 우리가 모은 순간들 —"). 흰색 + 텍스트 그림자.
- 캔버스 위 그라데이션 오버레이: 위에서 아래로 투명 → 베이지 살짝(접경부에서 폼 영역과 자연스럽게 이어지도록).

### 6.3 폼 영역

위에서 아래로:

1. 라벨 — `"Family Archive · 입장"` (로그인) / `"Family Archive · 초대"` (가입). 9~10px, sans, uppercase, gold-soft.
2. h1 — 로그인: "다시 만났어." / 가입: "처음 만났어." `var(--font-serif)`, 42px.
3. 부제 — italic serif, 14px, ink-muted.
4. 입력 필드 — `border: none; border-bottom: 1px solid var(--color-border)`, 박스/카드 없음. 라벨은 placeholder italic serif로. 포커스 시 보더 색이 `--color-wine`.
5. CTA — 와인 알약, 풀폭, 12px uppercase sans, `letter-spacing: 0.2em`.
6. 보조 링크 — italic serif, 11px, ink-muted. "초대장이 있어? <u>가입하기</u>" (로그인 페이지에서). 가입 페이지에서는 표시 안 함.

폼은 카드/테두리 없이 종이에 적힌 듯한 흐름.

## 7. 모바일 규칙 요약

- 그리드 컬럼: 2 (CSS `columns: 2`).
- 칩 행: 가로 스크롤.
- 톱바: 메뉴 텍스트 숨김, 알약 CTA만.
- 캡션: 그리드에선 항상 숨김, 라이트박스 메타 패널에서만 표시.
- 라이트박스: 세로 스택. 사진 위 / 메타 아래.
- 로그인: 사진 위 / 폼 아래 스택.
- 폰트 크기: 데스크톱 대비 h1 -14px, h3 -6px, 본문 동일.

## 8. 구현 메모

- **MasonryLayout** 컴포넌트: 라이브러리 없이 CSS `columns`로 충분. 자식에 `break-inside: avoid` 필수.
- **호버 캡션**의 `data-large` 판정: 업로드 시점 sharp 메타에서 얻은 `width`/`height`로 짧은 변을 계산해 DB `media.short_edge_px`로 저장 → 그리드 렌더 시 `short_edge_px >= 300` 조건으로 클래스 부착. (부모 §4의 media 스키마에 컬럼 한 개 추가 필요.)
- **로그인 배경 사진 무작위 선택** 엔드포인트: `GET /api/login-cover` — 위에 설명한 일별 캐시 쿼리. 인증 불필요(공개).
- **랜덤 사진 노출 동의**: 로그인 페이지에 가족 사진이 한 장씩 노출되는 점은 가족 외부에 노출될 수 있는 표면(누구나 접근 가능한 URL)이므로, **관리자가 "로그인 배경에 사진 사용" 토글을 끄면 fallback 정물화로 대체**해야 한다. `users` 테이블엔 부적합, 새 `settings` 단일 행 테이블이 필요. (부모 §11 설정 패널에 항목 추가 필요.)
- **폰트 로딩**: `next/font/google`로 `Cormorant_Garamond`, `Noto_Serif_KR`, `Inter`, `Pretendard`를 layout에서 prefetch. `font-display: swap`.
- **이미지**: 그리드 타일은 `next/image` 사용 + `sizes` 정확히 — 모바일 50vw, 태블릿 33vw, 데스크톱 25vw. 라이트박스는 medium 키, 영상 재생 시점만 original.

## 9. 부모 spec에 적용해야 할 변경

이 문서를 채택하면 부모 `2026-05-14-family-gallery-design.md`에 다음 수정이 필요하다:

1. §9 (UI / 디자인) 머리말에 "세부 규칙은 `2026-05-21-design-pattern.md`를 따른다" 추가.
2. §9.2 (장식 요소) — "1px 골드 보더 + 코너 장식", "FAB(좌하단 업로드, 우하단 설정, 상단 휴지통)" 표현은 이 문서의 톱바·칩과 충돌하므로 **삭제**. 단, "종이 텍스처 SVG"는 옵션으로 남겨도 무방하며, 채택 여부는 구현 폴리시 단계에서 결정.
3. §9.3 (모바일 우선) — 그리드 컬럼 수만 남기고 나머지는 §3·§7로 이관 (중복 제거).
4. §4 (데이터 모델) `media` 테이블에 `short_edge_px integer not null` 컬럼 추가.
5. §11 (설정 패널)에 "로그인 배경에 사진 사용" 항목(관리자 전용) 추가. 저장 위치는 새 `settings` 테이블의 단일 row.
6. §16 (향후/스코프 밖)에 "별도 캡션 컬럼(`media.caption`) 도입" 후보로 추가.

## 10. 스코프 밖

- 편집 캔버스, 휴지통, 관리자, 설정 화면의 시각 디자인. (이번 패턴 미적용. 부모 §9의 기존 르네상스 폼.)
- 카테고리(앨범/태그) 시스템 — 칩 행은 현재 분류 필터 3종만.
- 다크 테마에서의 톱바/히어로 상세 — 토큰은 이미 양쪽 정의돼 있으나 픽셀 단위 시안은 구현 단계에서 결정.

## 11. 검증 방법

이 패턴을 구현한 뒤 다음으로 확인한다:

- 갤러리 `/gallery` — 데스크톱(4컬럼)·태블릿(3)·모바일(2) 각각에서 마운트해 컬럼 수와 캡션 표시 규칙이 정확히 §3.1·§3.2와 일치하는지 브라우저에서 직접 본다.
- 라이트박스 — 사진 1장 / 영상 1편으로 데스크톱·모바일 양쪽 확인. `Esc` / 스와이프 / 키보드 좌우 작동.
- 로그인 — 사진 있는 상태(seed 데이터)와 없는 상태(빈 DB) 둘 다 fallback이 잘 뜨는지 확인.
- Lighthouse 모바일 ≥ 90 (부모 §9.3 목표 유지).
